# Lighter ↔ OKX RWA / TradFi 对照矩阵（2026-11-09 生成）

数据来源：两所公开 REST（实时盘口 5 档 + 14 天小时线）。生成脚本 `scripts/rwa_matrix.py`。
价格单位：OKX `*-USDT-SWAP`（USDT 结算永续）/ 现货 `X<BASE>-USDT`；Lighter 为 USDC 结算永续 / Robinhood-chain 现货。

> **列说明**
> * `OKX 价差 / Lighter 价差`：**当前时刻**盘口买卖价差（bps，相对中间价），快照，不是历史均值。
> * `14d 基差 p50/p95`：两所中间价归一化后的**跨所基差**（Lighter/ratio − OKX）/OKX，14 天小时线；p95 取绝对值分布。
> * `RTH / 盘前 / 盘后 / 周末 p95`：同一基差序列按美国交易时段切分后的 p95。
> * `b*` = 手续费 4bps（两腿各 2bps maker）+ 两所当前价差之和 + 1bp 逆向选择余量。
> * `p95 − b*`：正值才有毛边；≥ +2bps 才值得挂单。

## 六、读表要点

1. **时段 p95 是跨所基差，不是单所价差**。例如 KORU 周末 188bps vs RTH 19bps，说明周末两所报价脱节更严重（薄 + 陈旧），这与另一会话对 SPY 的"闭市 78×"观察同源，但幅度因标的而异。
2. **Lighter 价差普遍是 OKX 的 2–10 倍**（ASML 62 vs 9、IREN 83 vs 9、NOW 67 vs 4），这直接吃掉了基差。
3. **现货对更差**：SPY 现货 p95 15.7bps（永续只有 4.8）、QQQ 现货 38.8（永续 8.4），因为 Robinhood-chain 现货盘口只有 5–20bps 宽。
4. 结论与 11-08 的筛选一致：**RWA 里能做的不是"最大的名字"，而是价差相对窄、基差相对宽的中小票**（QQQ/CBRS/IBM 以及待验证的 SAMSUNG/SKHYNIX）。
